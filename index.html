Set it up.

You’ll need desktop Chrome and a GitHub repository with an initial commit.

  1. Load the extension

    Unzip the download. Open chrome://extensions, turn on Developer mode, then choose Load unpacked and select the extracted folder.

  2. Connect your repository

    Enable Device Flow in your GitHub OAuth app. Enter its client ID and your repository in the popup. Authorize the device code on GitHub, then reopen the popup.

  3. Submit a solution

    After an accepted verdict, check the commit in your repo. Identical code skips the extra commit.
